# Legal Skills Chinese 中文法律推理技能库

这是一个精心打造的中文法律推理技能库，包含 **38 个由执业法律专业人员手写并验证的法律推理技能**，覆盖检索 → 推理 → 论证 → 文书的完整链条。

## 📚 项目概览

- **38 个法律推理技能**：36 个原子能力 + 2 个复合能力
- **设计理念**：分层的法律推理体系，每个技能只做一件事，可独立调用、可相互组合
- **法域**：中国大陆成文法体系
- **应用场景**：法律研究、案件分析、法律文书撰写、合规咨询

## 🧩 技能分类

### 七大类别

| 类别 | 数量 | 代表技能 |
|------|------|----------|
| **01 · 信息检索** | 5 | case-retrieval · legal-article-retrieval · legal-norm-validity-check |
| **02 · 事实与要素处理** | 4 | legal-element-extraction · structured-element-extraction · dispute-issue-identification |
| **03 · 法律解释** | 4 | legal-interpretation-argument · systematic-interpretation · teleological-interpretation |
| **04 · 法律推理** | 7 | deductive-reasoning · analogical-reasoning · counterfactual-reasoning |
| **05 · 论证组织与评估** | 4 | argument-chain-construction · argument-strength-evaluation · evidence-argument-chain |
| **06 · 风险评估与价值判断** | 6 | dispute-and-performance-risk · judicial-value-judgment · legal-judgment-prediction |
| **07 · 文书与事务管理** | 8 | legal-document-formatting · judgment-document-generation · legal-document-summarization |

## ⚠️ 重要声明

- 本技能库是**辅助工具**，不提供法律意见
- 所有输出应由执业法律专业人员审核后方可使用
- AI 生成的推理可能存在偏差、遗漏或过时
- 最终的法律判断必须由具备执业资格的法律专业人员作出
