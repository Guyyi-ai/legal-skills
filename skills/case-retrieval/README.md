# 案例检索（Case Retrieval）

**技能编号**：09

**能力名称**：案例检索

**能力类型**：法律原子能力

## 快速描述

查找与当前法律问题相关的类似案例、相关判决、裁判规则的系统化检索能力。

## 何时使用

- 用户明确要求查找类似案例或判决
- 需要通过案例分析确定诉讼策略
- 需要了解法院对特定问题的处理倾向
- 为法律意见提供案例支撑

## 核心特性

- 基于法律关系、争议焦点的系统化检索
- 输出结构化案例报告（含案例摘要、裁判要旨、相关度评估）
- 多维度类案识别标准
- 对应司法实务的检索路径

## 关键限制

- 中国大陆法律体系为成文法体系，案例不具有普遍约束力（指导性案例除外）
- AI 无法直接访问实时案例库，需依赖真实法律数据库接入
- 案例遗漏或误引可能导致策略偏差
