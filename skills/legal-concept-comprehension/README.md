# 法律概念理解（Legal Concept Comprehension）

**技能编号**：08

**能力名称**：法律概念理解

**能力类型**：认知分析

## 快速描述

精准理解法律概念的内涵、外延、构成要件及法律效果的系统化分析能力。

## 何时使用

- 用户直接询问"什么是XX"或"如何理解XX"
- 要求比较两个法律概念的异同
- 给出具体事实询问是否构成某法律概念
- 在法律分析中遇到不熟悉的术语
- 需要拆解某概念的构成要件

## 核心特性

- 三层语义解析：生活语义 → 法律语义 → 教义学语义
- 构成要件体系化拆解
- 与邻近概念的边界辨析
- 法律效果分析
- 典型适用情形列举

## 关键限制

- 法律概念具有开放性和发展性，不同时期可能有不同理解
- 高度争议性概念（如"公序良俗"）不能仅靠要件拆解解决
- 本技能为学理层面的框架，不构成具体案件的法律意见
